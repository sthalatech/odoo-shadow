The full-context agent thesis — applied to Odoo

“What if every issue shipped with
its own prod-realistic, ready-to-run world?”

Running everything inside a single sandbox means the agent has the same low-latency access to services, files, and tools that an engineer would have locally. odoo-synth builds that sandbox per issue — a masked, pruned copy of the production database, the addons repo, and Odoo in one isolated workspace — then hands it to an autonomous agent that reads the report, implements the fix, and opens the pull request.

The shift: stop running standups the old way. Curate the issues, file them in GitHub, and assemble later to review the PRs — each one ready in 45–60 minutes, all running in parallel because every agent already has everything it needs in its own self-contained workspace.
